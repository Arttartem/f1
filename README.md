# F1 Portal

Сайт про Формулу-1 сезона 2026. Сделал для практики в вёрстке и чтобы собрать в одном месте информацию о текущем сезоне.

## Что это

Многостраничный сайт на чистых HTML, CSS и JavaScript. Без фреймворков и сборщиков — открывается двойным кликом по `index.html`.

## Какие страницы есть

Всего пять разделов.

**Главная** (`index.html`)
- Лидеры чемпионата — топ-6 пилотов с очками и отставанием
- Кубок конструкторов — топ-6 команд
- Ближайшая гонка — этап, дата, трасса, короткое описание
- Последние новости — четыре карточки про события сезона
- Полезные ссылки на внешние ресурсы (официальный сайт F1, FIA, Motorsport, Autosport и другие)

**Команды** (`teams.html`)
- Все 11 команд сезона 2026
- Для каждой указана база, мотор, количество титулов и состав пилотов
- Внизу три карточки с фактами про Audi, Cadillac и Haas

**Пилоты** (`drivers.html`)
- Все 22 пилота, сгруппированные по командам
- Номер болида, страна, короткое описание
- Блок интересных фактов про Боттаса, Хюлькенберга и Переса

**Календарь** (`calendar.html`)
- 22 этапа сезона 2026
- Дата, город, название трассы
- Отметка «СПРИНТ» у спринт-уикендов
- Внизу примечание про отмену Бахрейна и Саудовской Аравии

**Аварии** (`crashes.html`)
- Топ аварий начиная с 2014 года
- У каждой — описание, год, трасса, команда
- Поля под ссылки на видео, фото и источник (пока не заполнены)

## Что реализовано

- Плавные переходы между страницами — при клике экран затемняется, потом загружается новая страница
- У каждой страницы своё фоновое фото, фон плавно проявляется при загрузке
- Эффект матового стекла на карточках и шапке
- Анимация появления карточек
- Адаптив под мобильные и планшеты

## Технологии

- HTML5
- CSS3
- JavaScript без библиотек
