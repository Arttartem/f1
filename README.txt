F1 PORTAL — КАК ЗАПУСТИТЬ ПРОЕКТ

1. Что должно быть установлено
- Node.js (подойдёт актуальная LTS-версия).
- Редактор кода, например Visual Studio Code.

2. Запуск
- Распакуй папку проекта.
- Открой её в VS Code.
- Открой терминал в этой папке.
- Один раз выполни: npm install
- Для запуска выполни: npm start
- Открой в браузере: http://localhost:3000

Важно: не открывай index.html двойным щелчком. Сайт нужно запускать через сервер,
иначе запросы к API отзывов работать не будут.

3. Как устроен проект
- index.html — главная страница.
- teams.html — команды.
- drivers.html — пилоты.
- calendar.html — календарь.
- tracks.html — трассы.
- crashes.html — аварии.
- style.css — оформление всех страниц.
- script.js — общие действия браузера и форма отзывов.
- server.js — сервер на Node.js и Express.
- messages.json — файл, в котором хранятся отзывы.
- package.json — список зависимостей и команды запуска.

4. Как работает бэкенд отзывов
- Браузер отправляет GET-запрос на /api/messages, чтобы получить отзывы.
- Сервер читает messages.json и возвращает данные в формате JSON.
- При отправке формы браузер делает POST-запрос на /api/messages.
- Сервер проверяет текст, добавляет дату и ID, после чего сохраняет массив в messages.json.
- При следующей загрузке страницы отзывы снова читаются из файла.

5. Что можно поменять самостоятельно
- Тексты страниц находятся в соответствующих HTML-файлах.
- Цвета сайта собраны в начале style.css в блоке :root.
- Максимальная длина отзыва (500 символов) задаётся в server.js и проверяется в script.js.
- Число сохраняемых отзывов задаётся переменной MAX_MESSAGES в server.js.

6. Важное ограничение
Для учебного проекта хранение в JSON-файле подходит. Для большого публичного сайта
лучше использовать базу данных, добавить ограничение частоты запросов, модерацию отзывов
и защиту от спама. Данные о сезоне и расписании перед публикацией нужно сверять с FIA/F1.
